Mastering Two Pointers

The Two Pointers pattern is a clever optimization technique. Instead of using nested loops to compare every possible pair in a collection (which takes O(n²) time), we use two references—often called "pointers"—that move through the data strategically. This usually reduces the time complexity to O(n).

Intuition Builder: Alternative Perspectives

  • 📖
    The Dictionary Search (Opposite Directions) Imagine searching for a word in a dictionary. You don't read page by page. If you know the word starts with 'M', you grab the middle. Two pointers from opposite ends work similarly on sorted data: you use the sorted nature to eliminate whole sections of possibilities instantly.
  • 🏃
    The Fast & Slow Runner (Same Direction) Imagine two runners on a track. One runs twice as fast. When the fast runner finishes the lap, the slow runner is exactly halfway. This is used in Linked Lists to find midpoints or cycles without knowing the total length.
Pattern 1

Pair Sum (Sorted Array)

Problem: Given a sorted array of numbers and a target sum, find two numbers that add up to the target.
The Gut Feeling: Because it's sorted, the smallest numbers are on the left, largest on the right. If we pick the extremes (Left and Right) and their sum is too big, we must decrease it. How? By moving the Right pointer to a smaller number. If the sum is too small, we move the Left pointer to a larger number.

Pattern 2

Triplet Sum (3Sum)

Problem: Find all unique triplets in an array that sum to zero (i.e., a + b + c = 0).
The Gut Feeling: Three moving parts are too complex. What if we freeze one? If we fix a, the problem becomes finding b + c = -a. Suddenly, it's just the Pair Sum problem from above! We sort the array, iterate through it to fix a, and use Two Pointers for the rest.

Pattern 3

Valid Palindrome

Problem: Check if a string is a palindrome (reads same forwards and backwards), ignoring spaces and punctuation.
The Gut Feeling: A palindrome is symmetrical. We place a pointer at the very beginning and the very end. They act as mirrors of each other. We move them inwards, ensuring they always point to the exact same character. If they ever disagree, the mirror is broken!

Pattern 4

Container With Most Water

Problem: Given an array of heights, pick two lines that form a container holding the most water.
The Gut Feeling: Area is width × height. The height is bound by the shorter line. To maximize width, we start with pointers at the very ends. What do we move inward? If we move the taller line, the new height is still restricted by the short line, but the width decreased—area guaranteed to drop. Therefore, we always move the shorter line hoping to find a taller one to compensate for the lost width.
